## 📌 Overview

The **Emotion Detector Application** is an AI-powered web application that detects human emotions using **multiple input modalities**.  
Unlike traditional systems that rely on a single data source, this project integrates **text, facial expressions, voice signals, and images** to achieve more reliable and realistic emotion analysis.

This project demonstrates the practical use of **Artificial Intelligence, Machine Learning, Computer Vision, and Natural Language Processing** in real-world emotion recognition scenarios.

## 🚀 Features

🔹 **Text-Based Emotion Detection**  
Users can type messages or thoughts, and the system analyzes the text using NLP techniques to detect emotions such as *happy, sad, angry, stressed, or neutral*.

🔹 **Face-Based Emotion Detection (Real-Time)**  
Uses the device camera to analyze facial expressions and detect emotions using deep learning and computer vision.

🔹 **Voice-Based Emotion Detection**  
Users can record their voice, and the system extracts audio features like pitch, tone, and energy to identify emotional states.

🔹 **Image-Based Emotion Detection**  
Users can upload an image containing a face, and the model predicts the emotion present in the image.
